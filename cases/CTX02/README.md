## 这次学到了什么

DSH的摘要与后续基础请求中的选定文本块一致。WorkBuddy压缩记录仍保留五轮原业务输入；Codex替换历史也保留五轮用户原文，另有不可读压缩项。后两者不能表述为“只凭摘要找回数据”。

短历史上手动压缩，与接近上下文窗口容量时自动压缩不同；五款窗口不同，相同文字量也不代表相同压力。最终答对只说明这次内容保持正确，不能单凭它确认压缩、自动触发或内部责任。
