# FB03「截断后完整结果获取」

版本：1.0.0。工具返回内容过长时，可能只显示其中一部分，同时把全文保存在别处。本题生成固定256 KiB、即262144字节的模拟报告，检查截断后是否仍能取得正确全文。

- [第二阶段提示词及触发条件](prompts/第二阶段-触发后使用.md)
- [四项判分规则](rules.md)
- [五款逐项结果](../../results/information-feedback.md#fb03)

第一阶段在独立目录、新会话中运行一次程序，只记录首次实际返回，检查是否说明截断、是否提供可用全文入口。保留记录，不提前读取全文，不自行重定向输出创建入口。

确认工具结果确实被截断后，第二阶段在原会话中由人工明确要求产品使用首次入口，读回缺少的字段，并检查完整文件。入口和读取可用、全文保存准确是不同观察项，分别按运行前规则判分。

第二阶段是人工指令触发，因此本题不评价产品自主发现和处理截断的能力。没有触发截断或证据不足时留空；后续成功也不能倒推首次已经提供入口。不要把回执、规则或旧结果交给产品。
