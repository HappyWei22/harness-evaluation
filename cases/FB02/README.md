# FB02「较长结果回传」

版本：1.0.0。本题把短结果扩展为200行、17929字节的模拟报告，检查报告不同位置的四个关键字段是否保留，每项2分，共8分。

- [输入程序](input/long_feedback_probe.py)
- [实际使用的提示词](prompts/给产品的提示词.md)
- [判分规则](rules.md)
- [五款逐项结果](../../results/information-feedback.md#fb02)

在独立空目录放入程序，使用新会话。程序只运行一次，不使用筛选、重定向或包装程序缩短输出，也不主动改变工具的输出额度。只观察第一次返回；工具若提供全文入口，先保留入口，本题不继续读取。

评分检查运行编号、错误数量、错误路径和报告完成标记。程序生成随机编号，并给评测方保存回执，防止把旧结果当作本次输出。回执不是产品实际收到的内容，产品不能读取它补答案。

界面折叠、工具实际截断和日志导出缩略是不同情况，应依据取得的记录区分。日志中出现完整正文，也不能自动证明完整正文已经进入模型请求。具体证据范围随每条结果记录。
