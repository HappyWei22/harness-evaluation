# FB01「基础回传」

版本：1.0.0。工具执行程序后，应返回正常或失败状态及对应内容。本题分别运行正常模式和预设错误模式，检查状态及关键字段，共四项，每项1分。

- [输入程序](input/feedback_probe.py)
- [实际使用的提示词](prompts/给产品的提示词.md)
- [判分规则](rules.md)
- [五款逐项结果](../../results/information-feedback.md#fb01)

在独立空目录放入程序，使用新会话发送提示词。按顺序执行两次独立工具调用，每条命令一次。错误模式会故意失败，不能修复、重试，或在命令后增加会改变退出状态的包装。

程序会给评测方保存一份回执，记录本次预期输出。产品不能读取它补答案；评分时把实际工具返回与回执对照。若程序在生成预设字段前提前退出，需要先确认测试条件是否成立，不能直接判为回传丢失。

不要把整个仓库、评分规则、回执或旧结果提供给产品。五款模型和环境未完全统一，本题先检查实际行为，不能仅凭得分确定内部责任。
