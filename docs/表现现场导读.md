## 1. DSH：截断后按入口读回全文

任务为FB03「截断后完整结果获取」。固定程序生成262144字节报告；首次工具结果提示截断并给出入口。第二阶段由人工明确要求，产品使用该入口取回标记；保存文件与预期报告逐字节一致。

阅读[DSH四项判断](../results/information-feedback.md#dsh-fb03-01)，其中证据链接指向原始第21/22、38/39、72/73行的公开事件及完整文件。复核：

```bash
python3 checks/verify.py --item DSH-FB03-04
```

这支持本轮入口与保存可用，不证明自主恢复、全部模型输入或长期可靠性。
