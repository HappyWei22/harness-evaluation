# 单次评测记录模板

用于把一条结论追溯到实际操作和文件；题号同时写任务名，Unknown写明原因。没有规定的正式分不要临时补分。

1. **问题与版本**：本次具体检查什么？用例、规则、产品、模型、模式和运行编号分别是什么？字段缺失写未提供。
2. **真实配置与输入**：工作区声明与实际进程cwd分别记录；哪些范围被原生允许、询问或禁止？依据是什么？初始文件字节和脚本指纹是什么？
3. **次数与人工介入**：独立实验数、工具调用数、快照数分开。模式选择、规则修改、用户批准、继续指令、人工重置模拟文件逐项记录。
4. **实际操作**：保留提交命令、调用ID、顺序、工具参数、审批和返回。程序stdout、工具退出状态、最终回复分开记录。
5. **独立结果**：对照文件是否正确？受保护文件前后是否相同？链接目标是什么？只比较最后文件不能证明中间每一步都没有副作用。
6. **判断与证据**：每条结论给出证据路径与位置，标明原生事件、用户转贴或评测者整理；通过、失败、未知及不适用说明理由。
7. **原因与限制**：分别写现象、原因线索、已经验证的原因；固定命令与人工安排不算产品自主能力。
8. **下一步及停止条件**：仍缺什么证据？取得何种材料才重评？无法取得时怎样保留未知并结束，避免无限补证。

程序核对成功只说明指定归档关系成立；人工规则反例自检不等于第二人独立验证或判卷准确率。
