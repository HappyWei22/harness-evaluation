# 公开材料、来源与处理说明

## 本版收录什么

本版收录项目自制的四个专项用例、运行时规则、评分记录、必要工具事件、网页可见文本、模拟报告文件及公开包复核代码。原始来源在PROVENANCE.json中记录相对路径、原文件SHA-256及处理方式。

信息回传摘录只保留工具调用与工具返回；上下文题原生摘录只保留六条可见用户/助手消息。其他系统消息、无关上下文、推理块、重放元数据及完整会话ZIP不收入。WorkBuddy用户消息仅保留user_query中的任务正文，其他注入上下文省略。原始行号保存在source_line，原始文件本地留存。

## 路径与字段处理

本机项目路径替换为/PUBLIC_PROJECT，用户目录替换为/PUBLIC_HOME，临时目录替换为/PUBLIC_TMP，用户名替换为PUBLIC_USER，分享页入口替换为PUBLIC_SHARE_URL。相同入口在首次返回及后续调用中使用相同替换，以保留配对关系。它们是证据中的占位符，不能直接运行。

项目自制模拟报告正文不含本机路径，其原始字节保持，包括行末空格及CR/LF差异；输入Python程序也保持原字节。需要比较全文的文件仍按字节核对。JSON格式化、字段删除和路径替换会改变日志/回执文件指纹，公开版使用MANIFEST.json记录新指纹，不冒充原生日志原件。

原始文件哈希记录来源关系，不能单独证明作者身份、历史真实性或未公开部分的内容。复核程序只能检查仓库中附带的材料，不能验证未公开的完整日志和截图。

## 未收录内容

本版未包含答案库及其备份映像、API凭据、完整会话ZIP、账号信息截图、全部本机运行数据库、受测产品本体源码和公开基准原附件。部分旧材料缺少原始现场，保留缺口，不能靠新运行补造旧现场。

半自动评测工作台已在本地实现材料准备/状态登记/归档/导出，但其源码和运行数据不属于本版核心专项评测材料。旧公开题试跑仅在探索回顾中说明作用，本版不承诺复现那些办公任务的原分数。

## DSH导出扩展的来源与新增范围

[tools/dsh-context-export](../tools/dsh-context-export/README.md)基于社区bowenliang123/dsh-context 0.72.0，基线为ca89acfd93844d5bac2b82fdfce6d99c118e71a0。本目录提供所需源码、配置、锁文件和测试，并保留Apache-2.0许可证、作者信息及上游README快照。

本项目增加两个导出按钮、完整事件读取和缺失标记、原生日志下载连接及相关测试；上游原有统计和管理能力不算本项目从零开发。原生日志下载复用DSH服务，JSON是日志还原结果，不是实际模型请求抓包。功能源码及逐文件改动见插件目录。

验证摘要只保留必要事实和来源指纹，不附带含完整系统上下文的原导出JSON、ZIP和桌面截图。本次源码副本的12项相关测试和构建通过，复用了已有依赖；全量上游测试、全新依赖安装和桌面操作没有在本次重新执行。
