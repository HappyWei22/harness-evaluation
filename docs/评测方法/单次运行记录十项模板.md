# 单次运行记录十项模板

每次运行保存下面十项，另存同字段JSON。配置按各产品当时实际情况填写；未记录的写未知。证据链接放在证据等级栏，同题分析共用五段式报告。

| 项目 | 记录 |
| --- | --- |
| 唯一ID | 沿用既有运行标识，不增加实验次数 |
| 题目与脚本版本 | 编号、任务名及实际采用版本 |
| 产品版本 | 实际记录；未记录写未知 |
| 模型 | 实际名称及已知思考强度 |
| 工具 | 实际工具，可附工作目录；公开路径是占位符 |
| 权限 | 实际档位及已知人工批准情况 |
| 技能状态 | 实际配置；未手动添加不等于自动技能关闭 |
| 时间 | 实际执行日期、时区及计时口径 |
| 证据等级 | E1结果、E2过程、E3对照，按具体结论填写并附证据链接 |
| 最终裁定 | 原判断及适用范围；未知、失败、未执行分开 |

五段式任务报告采用：观察—证据—解释—未排除因素—可复现实验。旧版长模板保留为历史资料，后续采用本页十项结构。
