# WorkBuddy 目录创建异常的本地边界复现

2026 年 11 月 5 日。关联原运行 `WB-MKDIR-ABA-20261028-a01`，原实验归入评测端自测，共四组开关对照。公开脚本另执行一次核验，分别记录。两次均在本地完成，新增产品运行数为 0。任务来源见 [导师评语](https://github.com/HappyWei22/harness-evaluation/issues/1)。

## 一、观察

四组均符合预设。每组用同一路径重建初始状态，先关闭、再开启候选错误处理。调用固定为 `Path.mkdir(mode=0o777, parents=False, exist_ok=True)`，即请求创建一级目录，目标已经是目录时允许继续。

| 初始情况 | 本地文件系统两次均返回 | 关闭候选处理 | 开启候选处理 | 最终状态 |
| --- | --- | --- | --- | --- |
| 目录不存在，父目录可写 | 创建成功 | 正常返回 | 正常返回 | 创建了空目录 |
| 目录已经存在，内有标记文件 | `EEXIST`，目标已存在 | 抛出异常 | 正常返回 | 目标仍是目录，标记文件内容一致 |
| 目标是普通文件 | `EEXIST`，目标已存在 | 抛出异常 | 抛出同样的异常 | 目标仍是普通文件，内容一致 |
| 目标不存在，父目录禁止写入 | `EACCES`，权限拒绝 | 抛出异常 | 抛出同样的异常 | 目标仍不存在 |

表中的异常都是 Python 的 `PermissionError`。区分目标冲突与权限拒绝，要看底层错误码和异常携带的文本。

## 二、证据

- [预设样例](fixtures.json)记录初态、调用参数及开关两种状态各自应返回什么。执行前已经计算样例和脚本的 SHA-256 文件指纹，运行输出中的指纹与之相同。
- [原本地实验的脱敏输出](local-original.redacted.json)记录唯一运行编号、时间、Python 版本、权限和逐次请求、响应、异常、前后路径状态。每组开关前后只有请求流水号不同，响应字段相同。异常分支校验了返回给调用方的错误文本与代理收到的文本一致。这里是 E2 过程证据。
- 原本地脚本从归档代理提取四个函数，调用[原对照的候选处理](scoped_mkdir_intervention.py)，并由本机文件系统实际执行创建操作。两份归档代码的指纹均与原对照一致，见脱敏输出。临时目录绝对路径统一替换为 `<TEMP_DIR>`。
- [公开复现脚本](reproduce.py)使用评测者实现的代理替身。它仅模拟这四组需要的请求、返回和异常包装，直接调用相同的候选代码与本机文件系统，不需要安装 WorkBuddy。公开脚本的[核验输出](public-replay.json)独立于原本地实验，两份记录的四组开关对照均为 E3 对照证据，各自限于对应的执行路径。

## 三、解释

最有区分度的是已有目录与普通文件这一对。两者的底层错误码相同，但开启候选处理后，只有已有目录可以继续。归档候选处理要求调用允许目录已存在、只创建一级目录、收到来自执行侧的 `EEXIST`，并再次检查目标是目录。普通文件不满足最后一项。权限组实际收到的是 `EACCES`，因此原错误被传回。目录缺失组确实创建了目录，说明这条已有目录的处理分支没有干扰该样例的成功路径。

结合[原产品对照](../../../docs/故障归因/2026-10-30/WorkBuddy目录创建异常原因验证-五段式.md)，可以把解释收在这条路径上。代理将后端错误包装成 Python 异常后，候选处理只在本次符合条件的已有目录样例中把异常改成正常返回。四个本地样例内未发现错误放行，本轮保留原候选代码。

## 四、未排除因素

| 未验证条件 | 影响的判断 | 处理及停止条件 |
| --- | --- | --- |
| 产品的实际通信、权限策略及策略拒绝的响应 | 本地权限组验证的是本机文件系统拒绝，产品策略如何拒绝仍未知 | 四组本地判据通过后停止。若以后专门验证产品权限策略，再按实际响应设计对照 |
| 符号链接、并发替换、递归和其他参数 | 候选处理在这些条件下的行为仍未知。例如目标可能在收到 `EEXIST` 与检查目录类型之间被替换 | 本轮固定目标状态与参数。若以后评估可部署修复，再单独设定这些条件与判据 |
| 其他执行环境及独立人工复核 | 当前结果来自本机这一轮评测端自测，尚无跨环境复现或独立验收结论 | 保留脚本和输出供复核。本地四项完成后收尾 |

## 五、可复现实验

在本目录用具有普通用户权限的 macOS 或其他支持 Unix 文件权限的环境执行。公开脚本会为每个开关状态重建样例，创建和清理都在临时目录内。权限组把临时父目录设为 `0500`，保留读取与进入权限、去掉写权限，执行后恢复。

```bash
python3 -I -S -B reproduce.py
```

退出码 0 表示四组结果、实际路径状态、代理通信及函数恢复均符合预期，预期中的异常也算通过。普通文件或权限拒绝若正常返回，就是推翻候选处理在该样例中正确的反例，应保留输出并检查条件。若运行环境没有返回预设的 `EACCES`，该组初始条件未产生目标错误，应换普通用户环境再验证，不能据此判定候选处理吞错。保存重跑输出时使用新文件名，脚本会生成新的运行编号。
