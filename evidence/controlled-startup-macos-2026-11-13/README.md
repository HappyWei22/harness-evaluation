# macOS DSH 受控启动 · 11 月 13 日脱敏核验包

本包回应第 5 周周报反馈中「必须修改与验收」第 2 条。包含 11 月 13 日在 macOS 上为 DeepSeek Harness（DSH）加外层读取限制的七个模拟场景和一次真实诊断。外层启动器为 `dsh-gate-6`，组合指纹 `923f33f8436e`，真实诊断使用 DSH `0.2.2-rc.2`。 [Issue #3](https://github.com/HappyWei22/harness-evaluation/issues/3)

## 下载和核验

下载 [核验包 v2（ZIP）](macos-dsh-verification-v2.zip)，解压到空目录，进入解压后的包目录，用 Python 3.9 或更新版本运行。

```sh
python3 -B -E -s verify.py
```

包内有版本快照、逐场记录、真实工具返回、证据缺口说明和仓库外验收输出。核验只读取归档文件。退出码 0 表示核验通过，诊断结果由逐项输出给出。

| 核验对象 | 复算结果与范围 |
| --- | --- |
| 七个模拟场景 | 七项与历史裁定一致。原逐行提交日志缺失，按现存启动、拒绝和结束记录与当时汇总核对计数。并发被拦一侧的返回码仅见当时汇总。 |
| 三个清理场景 | 后台残留、启动器崩溃、清理后恢复逐项核对当时汇总中的清理命令返回，以及结束记录中的标签和残留进程。v2 在临时副本将任一清理返回码改为 1 时均退出 1。 |
| 真实诊断 `DIAG-ACCOUNT-20261113-02` | **部分通过**。7 次带用量的模型回复和 14 对工具调用与返回可配对。文件工具可用，指定外部探针被拒读，3 次 Bash 都在命令执行前失败。会话完成、进程正常退出，作业残留扫描为空。 |

本次验收为离线复算，新增产品运行与模型调用均为 0。Windows 虚拟机的验收另见 [11 月 17 日方案与验收](../../docs/阶段进展/桌面端Agent受控启动方案与验收-2026-11-17.md)。
