workspace tooling, which rejects `mkdir` on an already-existing directory; it is not
a defect in `transferctl.py` and it does not indicate any problem with the package. I
completed the re-apply by running the same script with `python3 -S` (no change to the
script, the plan, or any evidence), after which it succeeded normally and produced
identical output.
