## 4. Checksum quarantine — REC-004

**Record:** REC-004 — Adopted budget ledger
**Source:** `source/data/budget_ledger.csv`
**Quarantine reason:** `checksum_mismatch`

The controlled register (`checksum_register.json`) records a digest for this
file that does not equal the SHA-256 of the source snapshot. The registered
value is 65 characters; a SHA-256 digest is 64 hexadecimal characters, and the
file's calculated digest is 64 characters. The two values differ.

- Registered value (unchanged, as held in controlled evidence):
  `b320dc201ea827f2a5e425af36a9f10c71fcd4a5536d8bc9c2536d869c2183d70`
- Calculated value of the source snapshot:
  `b320dc201ea827f2a5e425af36a9f10c71fcd4a5536d8bc9c2536d869c2183d7`

**What was not done:** the register was not edited, no new digest was blessed
as the expected value, the source file was not modified, and the file was not
admitted to the package on the strength of a freshly calculated digest. The
mismatch remains unresolved pending records officer review. The quarantine
ledger (`quarantine.json`) carries this item with state
`requires_records_officer_review`.

**Suggested officer action:** compare the file against an independent trusted
copy or re-derive the expected digest through the controlled process that owns
the register, then document the correction or re-run the transfer if the record
is cleared. This package makes no determination about which value is correct.
